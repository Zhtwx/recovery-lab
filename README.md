# Recovery Lab

Lululemon Recovery Lab body care collection portfolio, with responsive layouts for phones, tablets and desktop browsers.

## Website

https://zhtwx.github.io/recovery-lab/

## Pages

- `index.html`: default entry point
- `lululemon-care-project.html`: collection and marketing strategy
- `lululemon-recover-details.html`: Recover products, experience and promotion

All images, styles and scripts are embedded. No build tools or external dependencies are required. Keep the three HTML files in the same directory.

GitHub Pages publishes the root directory of the `main` branch.
